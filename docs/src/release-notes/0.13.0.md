### **Rust Coreutils 0.13.0 Release:**

We are happy to announce the release of **Rust Coreutils 0.13.0** - a release focused on **GNU compatibility of options and edge cases, and on safer file handling**.
Most of the work went into the details that break scripts: conflicting or ambiguous options in `sort`, `date` format flags, `dd` conversions, `ls` time styles, `tail --follow` on symlinks, and what `cp`, `mv`, `ln` and `install` do when the destination is a symlink or a directory.

Alongside that, several utilities got faster (`basenc` base58 about 35x, `cut` +23%, `date` +22%, `join` +20%, etc), the WASI port got a lot of integration test coverage, a few more dependencies were dropped in favor of `std`, and more utilities now handle non-UTF-8 input.

We are now at **684 passing, 23 failing, 0 errors** on the GNU test suite.

Counting only the tests that actually run, we are at **684/707 (96.7%)**.

### Highlights:

- **GNU Compatibility**
  - `sort` rejects conflicting `-t`, `--compress-program` and `--check` modes, validates `--parallel` like GNU, and rejects `--debug` together with `-c`/`-C`; merge batches and temporary files are handled more carefully
  - `date` matches the GNU case flags on `%c`, `%p`, `%P`, `%r` and `%Z`, keeps leading zeros of `%N` with a width, and uses the locale date format verbatim
  - `dd`: `conv=ibm`, `conv=block` and `conv=unblock` behave like GNU, and `excl`/`nofollow` are checked before seeking in an output FIFO
  - `ls` accepts unambiguous `--time-style` prefixes, applies two-line time formats to old and recent files correctly, and sorts command-line arguments by version properly
  - `tail` follows a symlink to its target, accepts the obsolete `-cf` form, and clamps `--max-unchanged-stats` instead of overflowing
  - `printf` and `seq` fix `%f` padding past 1000 zeros; `split` accepts a leading `+` in every number and retries short writes; `pr`, `numfmt`, `stty`, `stat` and `od` align more options and messages with GNU

- **Safer File Handling**
  - `cp` no longer writes a recursive copy through a symlinked target, and checks relative symlink destinations against the working directory
  - `mv` and `ln` refuse to replace a directory with a symlink (or with `--backup`, `-f`, `-i` in `ln`)
  - `chown`/`chgrp` judge `--preserve-root` on the stat the traversal is pinned to; `chmod -R -L` reports dangling symlinks
  - `install` backs up a dangling symlink destination; `install`, `cp` and `mknod` warn when an explicit security context is ignored
  - `rm` escapes the operand in the `--preserve-root` error message
  - `uucore`: fixed `EOVERFLOW` in safe traversal

- **Robustness**
  - Panics fixed on write failures for verbose output in `rmdir`, `chcon`, `cp` and `tail`, on write errors in `numfmt`, and in `printf`/`seq` on zero
  - Non-UTF-8 input is now preserved in `date` (format strings and `--reference`), `stat` error messages and `shred` diagnostics
  - `uucore` parses a NaN payload such as `nan(1)` and quotes a lone brace in the shell quoting styles; `c-maybe` quoting is supported

- **Performance**
  - `tr` deletes bytes faster, `basenc` encodes and decodes base58 faster, and `od` streams its output line by line instead of buffering it

- **Dependency Diet**
  - `chroot`, `sync` and the permission helpers use `std` instead of `rustix`; `cp` and `dd` use `set_len` instead of `ftruncate`; `uucore` no longer needs `unsafe` for `gettid`

- **Cross-platform Reach**
  - WASI: integration tests enabled for `seq`, `mv`, `fmt`, `readlink`, `dircolors`, `cksum`, `realpath`, `nproc`, `shred` and `join`, a macro to document why a test is ignored, `date` clock support, and `nice` is no longer part of the default WASI build
  - Windows: `ln` converts `/` to `\` in symlink targets, and `cp` handles a recursive copy of a root such as `W:/`
  - `uucore` detects ASIMD on big-endian aarch64 and builds `stty` on little-endian ppc64

- **Upstream**: while chasing compatibility we found behavior GNU's own suite did not cover, and contributed **82 commits** to GNU coreutils during this cycle, almost all of them new tests for edge cases both implementations share, plus two small fixes (`tail`, `fmt`)

- **Contributions**: This release landed **931 pull requests** from **92 new contributors**
